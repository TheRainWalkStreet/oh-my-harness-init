# 术语表

| 术语 | 含义 |
| --- | --- |
| harness | 为 Agent 提供稳定上下文、规则和知识入口的仓库结构。 |
| 已有项目 | 已有源码、构建配置、包管理配置、框架骨架或可运行入口的项目。 |
| Lite | 小型或框架刚搭好的项目结构档位。 |
| Standard | 多数企业级业务项目的默认结构档位。 |
| Extended | 由复杂度或生产事实触发的扩展结构档位。 |
| AGENTS.md | Agent 入口地图，指向详细文档。 |
| ARCHITECTURE.md | 系统地图、层级边界和关键数据流。 |
| ENGINEERING.md | 本地开发、测试、构建、协作流程入口。 |
| coding.md | 项目适配后的代码规范。 |
| commits.md | 提交信息、提交粒度、PR 描述规范。 |
| Exec Plan | 多步骤任务的可版本化执行计划。 |
| active | 正在执行的计划目录。 |
| completed | 已完成计划的归档目录。 |
| 前后端一体 | 前端和后端在同一工作空间中维护但未必是 monorepo 的项目形态。 |
| 待确认 | 仓库事实不足，不能编造，需要用户或后续代码事实确认。 |
