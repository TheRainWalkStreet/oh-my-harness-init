# SECURITY.md 模板

用于生成 `docs/SECURITY.md`。

```markdown
# 安全边界

## 敏感信息处理

- 不提交密钥、token、账号、内部地址、真实用户数据。
- 环境变量示例只能使用占位符。
- 日志不得打印密码、token、身份证件、支付信息等敏感字段。
- 如果仓库已存在明文敏感配置，只记录风险类别和治理建议，不在本文档复制具体值。

## 认证与授权

{记录已发现的认证方式、权限边界、会话机制；未知写待确认。}

## 配置与环境变量

| 配置类别 | 来源 | 是否可暴露到客户端 | 备注 |
| --- | --- | --- | --- |
| `{类别}` | `{文件/平台}` | `{是/否/待确认}` | `{备注}` |

## 输入校验

- 外部请求参数。
- 表单输入。
- 文件上传。
- 第三方 API 响应。
- 数据库读取结果。

## 数据存储与隐私

{数据库、缓存、日志、对象存储、备份、隐私数据处理。}

## 外部 API 与供应链

{第三方服务、SDK、包管理、依赖更新、锁文件。}

## 前后端一体安全

{仅前后端一体项目生成。覆盖 CORS、CSRF、Cookie、认证态、静态资源托管、浏览器可见环境变量。}

## 禁止写入文档的信息

- 真实密钥或 token。
- 内部 IP、内网域名、生产账号。
- 未公开漏洞细节。
- 真实用户数据。
```
