# SECURITY.md 模板

用于 `docs/SECURITY.md` 的模板。从第 0 阶段发现的信息填充 —— 描述模式，不要写入密钥。

## 排除规则

docs/SECURITY.md **禁止**包含：
- 实际的密钥值、API Key 或 Token
- 用于密钥的具体环境变量名（使用通用描述代替）
- 内部基础设施详情（IP 地址、内部主机名、端口）
- 已知但未修复的漏洞详情
- 凭证存储的精确文件路径

使用通用描述：例如"数据库凭证从环境变量加载" —— 而不是"`.env` 中的 DB_PASSWORD"。

- **无认证：** 跳过认证和授权（例如 CLI 工具、静态网站）
